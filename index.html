Tata Cara Upload ke GitHub

  1. Extract file ZIP ini.
  2. Buka GitHub dan buat repository baru, contoh: finance-dashboard.
  3. Upload file index.html ke repository.
  4. Masuk ke Settings → Pages.
  5. Pilih Deploy from a branch, branch main, folder /root, lalu Save.
  6. Tunggu 1–3 menit sampai link GitHub Pages aktif.
  7. Buka link website, login dengan password 0803.
  8. Masuk panel GitHub Sync, isi Owner, Repo, Branch, File Data, dan Token.
  9. Klik Save Data ke GitHub. File finance-data.json akan dibuat otomatis.

Token GitHub yang Dibutuhkan

  1. Buka GitHub → Settings → Developer settings → Personal access tokens.
  2. Buat Fine-grained token.
  3. Pilih repository dashboard kamu saja.
  4. Permission: Contents Read and Write.
  5. Copy token ke panel GitHub Sync.
Masalah umum:
401 = token salah/expired.
403 = permission token kurang.
404 = repo/file/branch salah.
409 = konflik data, klik Load lalu Save lagi.
Network Error = internet/CORS/browser issue, sistem akan retry otomatis.
